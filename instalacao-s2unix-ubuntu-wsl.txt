================================================================================
   GUIA DE INSTALAÇÃO DO SEISMIC UNIX (SU) NO WSL UBUNTU 26.04 (GCC 14/15)
================================================================================

PASSO 1: INSTALAR DEPENDÊNCIAS DO SISTEMA (X11 / MOTIF / BUILD TOOLS)
--------------------------------------------------------------------------------
Execute o comando abaixo no terminal para instalar o compilador e todas as 
bibliotecas gráficas necessárias em uma única etapa:

$ sudo apt update && sudo apt install -y xorg gcc make libx11-dev libxt-dev libxext-dev libmotif-dev libtirpc-dev


PASSO 2: CONFIGURAR FLAGS DO COMPILADOR PARA CÓDIGO C LEGADO
--------------------------------------------------------------------------------
Como os compiladores GCC modernos tratam avisos de código C antigo (C89/K&R) como 
erros fatais, é necessário ajustar as flags de compilação.

1. Acesse o diretório de fontes do SU:
   $ cd $CWPROOT/src

2. Abra o arquivo de configuração de compilação:
   $ nano Makefile.config

3. Localize e substitua a variável CFLAGS para Linux com o seguinte conteúdo:

CFLAGS = -O2 -std=gnu89 -w -Wno-error=incompatible-pointer-types -D_DEFAULT_SOURCE -D_XOPEN_SOURCE=700 -D_FILE_OFFSET_BITS=64 -D_LARGEFILE64_SOURCE -DCWP_LITTLE_ENDIAN -DSUXDR -DSUTIRPC


PASSO 3: LIMPAR E COMPILAR O NÚCLEO E UTILITÁRIOS GRÁFICOS
--------------------------------------------------------------------------------
Ainda no diretório $CWPROOT/src, execute a limpeza e os dois comandos de 
compilação em sequência:

$ make clean
$ make install
$ make xtinstall

* make install  : Compila as bibliotecas base e utilitários em linha de comando.
* make xtinstall: Compila a suíte gráfica X11/Motif (incluindo o ximage).


PASSO 4: VALIDAÇÃO E EXECUÇÃO
--------------------------------------------------------------------------------
1. Verifique se o executável gráfico foi criado corretamente:
   $ ls -l $CWPROOT/bin/ximage

2. Execute a visualização de um arquivo de dados sísmicos no WSL:
   $ suximage < seu_arquivo.su &
