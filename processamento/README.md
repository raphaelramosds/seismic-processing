# scripts processamento

gerar secoes sismicas pela abordagem convolucional

- `refletividade_1d.ipynb` mostra como gerar uma seção sísmica a partir de um modelo de refletividade 1D, utilizando a convolução com uma onda sísmica.
- `refletividade_2d.py` mostra como gerar uma seção sísmica a partir de um modelo de refletividade 2D.
- `refletividade_2d_difracoes.py` mostra como gerar uma seção sísmica a partir de um modelo de refletividade 2D, incluindo difrações.
